Eficiencia computacional del Slicing vs. Ciclos for
Operaciones vectorizadas a nivel de C (NumPy C-API):
El slicing de NumPy no ejecuta el bucle en Python puro. 
Delega la operación a código precompilado en C/Fortran, 
el cual utiliza instrucciones SIMD (Single Instruction, Multiple Data) 
del procesador para manipular arreglos completos en paralelo a nivel de hardware.
